# 星海寄願所｜多語言體驗版

## 已包含
- 預設簡體中文，可切換繁體中文、英文、日文、韓文。
- 記住使用者上次選擇的語言。
- 天燈造型選擇：傳統、愛心、狗狗頭、星球、月亮、星星。
- 白色燈面繪圖區，可選顏色與筆刷大小。
- 放飛動畫、心願列表、聊天室介面。
- 心願與聊天示範資料存在目前裝置的瀏覽器 localStorage。

## 如何使用
1. 解壓縮 ZIP。
2. 確認 `index.html`、`style.css`、`app.js` 三個檔案在同一個資料夾。
3. 用瀏覽器開啟 `index.html` 即可預覽。
4. 部署到 GitHub Pages 或 Cloudflare Pages 時，將這三個檔案放在儲存庫根目錄。

## 重要限制
這是前端體驗原型，不是已完成的多人線上服務。localStorage 只會保存在目前瀏覽器與裝置，其他粉絲不會看到這裡的留言或聊天室訊息。要做成所有人共用的星海，需要再加入雲端資料庫、伺服器端 API、即時同步、內容檢舉與管理功能。

此版本使用 Google Fonts 網路字型；天燈動畫與介面本身不需要付費服務。免費託管平台可能有使用額度或服務政策變動，不能保證永久不中斷。建議保留 ZIP 備份。
